# The adversarial suite

One place for every failure class the design names (US11.5, FR11.5, NFR1): what the hostile input
is, what crankpath must do with it, and where the tests are. The machine-checked index is
[`suite.ts`](suite.ts) (each reference names a test file, describe title and test title, and
[`suite.test.ts`](suite.test.ts) fails when one no longer matches); the cases no earlier bolt
tested through the whole command are in [`gaps.test.ts`](gaps.test.ts). Every case asserts a named
outcome and has a control: the same input without its hostile part gives a different result.

| Class                   | Hostile input                                                                                                                                                | Expected outcome                                                                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `hostile-chart`         | a Helm chart with a file:// dependency outside the root, http, IP, loopback or userinfo repositories, a symlink, a lookup, a schema $ref, a YAML-bomb render | the Application is opaque with a named reason (unsupported-field, unreadable-file, limit, render-failed); nothing outside the root is read; the run finishes |
| `hostile-kustomization` | a kustomization with remote bases, an escaping resource, exec or plugin generators, helmCharts                                                               | remote-base, render-failed or unsupported-field before kustomize runs; no generator executes                                                                 |
| `symlink-escape`        | a file or directory symlink in the scanned tree pointing outside it                                                                                          | named and counted as a symlink (unreadable-file), never followed; the counts become a floor                                                                  |
| `path-traversal`        | `../` in an Application path, a value file, a crank target or a repos: read_from                                                                             | unreadable-file or a refused crankpath.yaml key, naming the field; nothing outside the root is read                                                          |
| `look-alike-url`        | a repoURL that looks like the scanned repo but is not (other host, host prefix, longer name, prefix or sub-path, case, port, punycode)                       | unreadable-repo: the repo is never assumed to be the scanned one                                                                                             |
| `dormant-cycle`         | a dependsOn cycle closed by one patch (dormant in the controller until the next revision)                                                                    | the extracted cycle is found on the revision that carries the patch, and not before                                                                          |
| `zero-applications`     | a repository with no Application, ApplicationSet, Kustomization or HelmRelease                                                                               | NOTHING ANALYSED, exit 2, never a clean result                                                                                                               |
| `yaml-bomb`             | an alias bomb in a scanned file, a values file or a render's output                                                                                          | a named refusal (unreadable file, or limit for a render), counted; the run finishes                                                                          |
| `deep-nesting`          | deeply nested YAML or JSON, HCL blocks, auth blocks                                                                                                          | too-deep (or a named HCL refusal), never a stack overflow                                                                                                    |
| `size-count-time`       | huge files, huge renders, too many documents or objects, a render that never ends                                                                            | a counted limit outcome (too-large, limit, timeout) and a floor; never silence, never a crash                                                                |
| `hostile-names`         | names and values with terminal escapes, newlines, `/` `:`, forged ids, bidi, NUL, claim words, long text                                                     | quoted after a fixed label, escaped for each destination, never at a line start, never a forged node                                                         |
| `crank-everything`      | a crankpath.yaml in the scanned repo that cranks every path and declares every external available                                                            | the cycle is still shown (cranked, never gone); every crank documented and every external declared, not verified; the repo's words quoted                    |
| `repo-supplied-config`  | a crankpath.yaml in the scanned repo that maps repos outside the root or shadows an alias                                                                    | refused with the key path (exit 1), or the user's alias kept                                                                                                 |
| `credentials`           | planted tokens, credentials, a kubeconfig or a proxy in the environment; userinfo in URLs                                                                    | no child process receives them; no token or userinfo in any output                                                                                           |
| `token-host`            | a repository that names a token host: a CRANKPATH_TOKEN_<HOST> set, and repo URLs or repos: entries that point elsewhere (AC11.5.3)                          | the token is read for its own host only and sent only to it over https; no other host's variable is read or sent; the token is in no output, cache or log    |
| `unknown-not-gone`      | a chart repository answering 403, 404 or 429, or unreachable                                                                                                 | private-chart or render-failed with "unknown whether the chart exists"; never gone, never a pass                                                             |

Mutation checks of the goldens (US11.6) are not here: each golden in `test/golden/` declares its
mutations in its `input.json`, and the golden harness requires each to change the result.
