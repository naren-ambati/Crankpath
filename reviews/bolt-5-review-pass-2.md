## 5. What I checked and found sound

- HostMatcher and `placeHost`: the only caller of `matchHost` is `resolveHost`, which carries `match.source` to the edge; every extractor that places a host goes through `placeHost` or `placeUrl` (Argo, Flux, secret stores, cert-manager, Vault seal). No path turns a declared match into an `extracted` edge (mutation: the source forced to `extracted` goes red [2]).
- External fallback agreement: an entry passes as agreement only when it names exactly the node the Service rules found, or exactly the external the shared fallback would name for that host; any other target, a wildcard entry whose target differs, an entry for an ambiguous or unplaced host, and an entry naming a Service of a foreign destination are overrides, listed per host with both targets and a gap (`s1` run). The match returned on agreement is the plain match, so the graph is unchanged.
- Hidden cycles: only computed when an override happened; compared by node set; a crank residual keeps its full node set in the reported cycle, so a crank is not blamed on a match entry (partial-crank plus unrelated-override run); the second extraction uses a separate matcher, so `unusedMatches` and `overrides` are not disturbed.
- Owners: every reason has an owner or is deliberately ownerless; `extractor-failed` and `match-limit` unverify every node; `argocd-namespace-unknown` unverifies every Application and ApplicationSet; `crank-unused` and `crank-target-unmatched` are ownerless and a gap; `argocd-namespace-assumed` and `-derived` are ownerless assumptions, named in the Assumed line (`Argo CD's namespace taken to be Namespace/argocd`) and `plan.assumes.argocdNamespace`. Residual: M1.
- `render:` targets: first crank wins; later cranks print `names N objects already created by an earlier step or target` and JSON `alreadyCreated` (thin slice, three overlapping cranks); only the first is credited on the cycle; the plan step of a no-op crank lists no nodes.
- Refined declared-facts rule: a declared edge or an overriding match entry is the gap; externals, `served_by` and cranks are listed assumptions and never a gap alone; the no-cycle line says `the result rests on N declared facts from crankpath.yaml`; an unspecified external is a gap. Mutating the rule either way turns tests red. Exception: M2.
- Hostile text: a `match` host or node with escapes or newlines is refused by ConfigReader with the key path quoted; hostile crank `by` text is quoted with visible codes (pass 1 and thin slice).
- Determinism and the derived `declaredEntries` limit: no change found.
