## 3. Checks on the new code paths

- **Raw copy.** Symlink targets: recreated as links, never followed. A symlink then a file or directory below it, a file then a directory of the same name, and the reverse (duplicate tree entries built with `--literally`): all four stop as `unsafe-tree`. `.GIT` as a directory name: stopped. A zero-width-character `.git` lookalike, tabs, newlines and backslashes in names: copied as plain names, nothing escapes. Case-colliding files: stopped (macOS). A symlink with an empty or absolute target: created, never followed. Executable bits: 0644 and 0755 only, chmod after write. Modes other than 100644, 100664, 100755, 120000, 160000: stop. Gitlinks: counted. All other entries are written with `wx`, so a write never goes through an existing link.
- **Gap-rise comparison.** The counted dimensions are the report's gap counts (opaque, unreadable, skipped, unresolved, run-limit files, jobs and edges, declared facts, submodules). Not counted and not gap reasons in the CLI: `droppedHooks`, `foreignDestination`, `ignoredFiles`, `declaredAssumptions`; the CLI's own gap reasons `no-dependency-edges` and `not-computed` are not compared either. I tried the foreign-destination, kind-typo, extension and namespace changes: each either moved a counted dimension (usually `unresolved`) or left the cycle in place, so none hid one. A cycle whose only link is a lost edge appears as an unresolved item, which is why the counts hold. The within-kind swap is m1.
- **Base equals head, merge base, gitlinks.** `base-is-head` and `no-merge-base` (shallow worded) are `NOT_CHECKED`; a head that is an ancestor of the base gives merge base equal to head, so `NOT_CHECKED`. A gitlink in only one side is a rise; in both sides the sides are compared and the gap is stated.
- **Shared chart cache.** One directory outside both copies; the base runs first (not pinned by a test, m4). The key is URL digest, chart name and exact version; a hit is used only in a trusted (outside-the-tree) root; a failed pull is not stored; the head cannot write an entry the base then reads. A local chart path is never cached.
- **Render timeout.** The `sleep` fake with a shortened wall clock ends `NOT_CHECKED` ("1 render timed out on the head"); `timeouts` on either side is a reason, mutation red (2 tests). The Action itself still has no timer (first-pass n2), and a hung CLI is bounded only by the job.
- **Harness runs the real step.** `scripts/action-local.mjs` reads the `check` step of `action/action.yml`; renaming an env name or changing the `base-ref` default turns 2 and 26 tests red.
- **Annotations and summary with the new rendered evidence labels.** A rendered edge's evidence is `render:<job>` and a Kustomize root's is `render:KustomizeRoot:<path>`, which can carry any path characters. `annotationFile` rejects any label containing `:` or `#`, so it is never an annotation `file` (mutation red, 3 tests); in the summary and the message the label sits after a fixed `file:` label inside quotes, with `::`, `,`, `%0A`, a newline, an escape character, backticks, Markdown links, HTML and `|` all encoded (`repros/p12.mjs`). Hostile Application and object names are skipped by the CLI (a counted gap) before they reach a label.
- **Determinism.** Two full harness runs, the second under `LANG=de_DE.UTF-8 LC_ALL=de_DE.UTF-8 TZ=Asia/Tokyo`, are byte-identical; no home path in the output.
