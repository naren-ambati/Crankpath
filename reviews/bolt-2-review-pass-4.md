The field golden (274 paths) equals the schema's paths (273 by my walk plus the one nullable array item my walker does not descend into); `toolchain.problems` is not in the JSON, as the notes say.
- **80-column text**: text and `--explain` output of six fixtures and a hostile estate (quotes, backslashes, CJK, runs of 100 characters, a label ending in `:`): no line over 80 except a single label with its quoted value (by design), no continuation line starts with a quote.

- **Closed proxy**: see section 4; a non-loopback URL reached through a pre-read gap stops at the proxy before any name is resolved.
- **Config pre-read**: nested kustomizations, components, a resource that is a kustomization directory, `configurations`, `validators`, plugin kinds `PatchTransformer`, `PatchJson6902Transformer`, `PatchStrategicMergeTransformer`, `ReplacementTransformer`, `ConfigMapGenerator`, `$ref` inside `openapi.path` and `crds` files (real kustomize does not fetch these; no request), a merge key hiding a path key, duplicate keys, a BOM, JSON, multi-document and a symlinked `.gitignore`: sound.
- **A cache inside the scanned tree** is not trusted; a `.crankpath` symlink is refused.
